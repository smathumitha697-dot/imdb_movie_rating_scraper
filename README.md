# IMDb Movie Rating Scraper

## Project Description
IMDb Movie Rating Scraper is a Python-based web scraping project that collects movie details such as movie title, rank, and IMDb rating from the IMDb Top 250 page using Selenium.

## Technologies Used
- Python
- Selenium
- Pandas
- Chrome WebDriver

## Features
- Scrapes movie details from IMDb Top 250
- Collects movie rank, title, and IMDb rating
- Uses Selenium for browser automation
- Stores the collected data in a CSV file

## Output
The scraped movie data is saved in a CSV file for further analysis.

## Project Purpose
This project was developed to learn Python, Selenium, web scraping, data collection, and data processing.
